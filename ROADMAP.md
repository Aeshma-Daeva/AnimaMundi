# Roadmap

This roadmap is organized by **authorization gates**, not aspirational feature lists. A later stage does not begin because an earlier result looks interesting; it begins only when its engineering and evidence contracts pass.

## Now — S3: physical-host qualification

**Goal:** determine the most stable and productive execution policy on the actual 128-vCPU machine.

- [ ] Capture CPU model, sockets, physical cores, SMT, NUMA, RAM, cgroup limits, and storage topology
- [ ] Verify the sealed repository and Python environment
- [ ] Run bounded mechanics and executor preflight
- [ ] Run adaptive worker probe: `8 → 64 → 128 → 96 → 112 → 32`
- [ ] Freeze throughput-optimal worker count `N*`
- [ ] Freeze verifier count, memory envelope, NUMA placement, and I/O policy

**Stop conditions:** any conservation/finite-state failure, swap/OOM, growing verifier backlog, projected RSS above 80%, storage risk, or parallel efficiency below 0.75.

## One-shot scientific campaign

### Primary census

Every primary cell runs exactly 128 ticks under three matched conditions:

1. Phase 6D archipelago longitudinal observation
2. Phase 6E baseline transit
3. Phase 6E closed-transit control

Primary quiescence never authorizes early termination.

### Deep sentinel atlas

Six preregistered Wave-1 cells receive deeper read-only observation:

- 2 fixed seeds × 3 conditions
- sampled ticks: `0, 8, 16, 32, 64, 96, 128`
- substrate, capsule, body, basin, weather, relationship, event-neighborhood, and cross-scale lead–lag records

### Exploratory succession

A separate lane runs frozen seeds through:

`32 → 64 → 128`

Continuation uses stage-local activity rules. Closed branches release their process and launch the next independent seed. They never inherit hidden state and never enter the unconditional 128-tick denominator.

## After the campaign

- [ ] Publish host qualification report
- [ ] Publish campaign manifest and verified artifact index
- [ ] Produce behavioral motif atlas
- [ ] Classify recurrent basin, body, relationship, and cessation patterns
- [ ] Identify candidate cross-scale causal pathways for matched experiments
- [ ] Decide whether a longer horizon is justified

## Medium horizon

Possible evidence-led trajectories:

- operational individuality as a multidimensional measurement;
- a taxonomy of structural, functional, lineage, memory, and attractor cessation;
- persistent relationship motifs and distributed organization;
- proto-semantic signaling assays with strict counterfactual controls;
- Demian as a bounded epistemic observer maintaining rival interpretations;
- matched clone experiments for cross-scale causal anatomy.

## Long horizon — not authorized

These are conceptual directions, not current commitments:

- observer–world feedback;
- inherited universe-level cosmogenesis;
- successor universes initialized from terminal residues or compressed motifs;
- a general comparative science of organized becoming.

They require separate constitutional and mechanism reviews.
